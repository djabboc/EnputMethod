# 布局感知的候选导航

状态：已记录，暂不实现。

## 目标行为

- 纵向候选：上、下键切换高亮项；左、右键翻页。
- 横向候选：左、右键切换高亮项；上、下键翻页。
- 快捷键动作根据当前候选布局解析，使快捷键语义与可见候选轴一致。

## 验收

- 在两种布局下测试每页首项、末项以及跨页边界。
- 验证默认快捷键和 `shortcut.json` 中同一动作的多个快捷键。
- 翻页和切换高亮时，候选框位置保持稳定。


## 2026-08-29 复核结论

这个导航轴决策仍有意延后。新的 WPF 翻页器已使用稳定的左右边缘控件，但没有改变键盘方向语义。不要把这项延后的设计变更混入翻页器视觉回归问题。
